# 🤖 Basic Rule-Based Chatbot (Python)

A simple command-line chatbot built in Python. It replies to user messages using predefined rules, with no external libraries needed.

## Features
- Responds to greetings like "hello" and "hi"
- Answers "how are you" and "what is your name"
- Handles unknown inputs with a default reply
- Runs in a loop until the user types "bye"

## Concepts Used
`if-elif-else` · functions · loops · input/output

## How to Run
```bash
python task4_chatbot.py
```

## Sample Output
```
Chatbot started. Type 'bye' to exit.
You: hello
Bot: Hi!
You: how are you
Bot: I'm fine, thanks!
You: what is python
Bot: Sorry, I don't understand that.
You: bye
Bot: Goodbye!
```
